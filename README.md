# BTCGuardiansHQ

**Secure, Non-Custodial Bitcoin Inheritance for Future Generations**

BTCGuardiansHQ builds free, open-source tools that let people pass Bitcoin to their heirs without relying on custodians, banks, or services that can fail or demand KYC.

## Why This Matters

Most Bitcoin inheritance solutions today depend on third parties. BTCGuardiansHQ takes a different approach — fully self-sovereign, air-gapped, and designed for long-term generational use.

## Key Features

- **Air-Gapped Signing** — Create and sign transactions completely offline using PSBTs
- **Shamir’s Secret Sharing** — Split your seed into multiple shards so no single point of failure exists
- **Fully Non-Custodial** — You stay in full control at all times
- **Designed for Heirs** — Built for long-term recovery, not just short-term convenience
- **Powered by a Genesis-Era Node** — Running continuously since 2009, providing independent, archival blockchain data

## Current Status

- Local version of the explorer is running
- Early vault functionality (including `vault.js` with Shamir’s Secret Sharing) has been tested
- Project is in active development
- Not yet publicly available

We are focused on building secure, usable tools before wider release.
