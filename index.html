THE PROCESS

Simple. Sovereign. Secure.

1️⃣

Create a Vault

Generate multisig + timelock addresses using our custom vault.js tool with proper Shamir’s Secret Sharing in a fully air-gapped Tails OS environment.

2️⃣

Split Your Keys

Divide your seed into multiple encrypted shards using real cryptographic Shamir’s Secret Sharing. No single shard reveals any information.

3️⃣

Set Inheritance Rules

Define clear conditions and time-locks. Store shards on metal plates in different geographic locations. Your heirs can recover the funds using your detailed recovery instructions.
