What is BTCGuardiansHQ?

BTCGuardiansHQ builds free, open-source tools for Bitcoin inheritance that prioritize self-sovereignty. The goal is simple: let people pass Bitcoin to their heirs without relying on custodians, banks, or services that can fail or demand KYC.

Why Our Node Matters

This project is powered by a Bitcoin node that has been running continuously since 2009. This gives us an independent, archival source of blockchain data that does not rely on third-party services.

  • Independent block validation
  • Full archival history (never pruned)
  • Reduces trust in external explorers or APIs

Key Features

🔒 Air-Gapped Signing
Generate and sign transactions completely offline using PSBTs.
🔀 Shamir’s Secret Sharing
Split your seed into multiple shards so no single point of failure exists.
✅ Fully Non-Custodial
You remain in full control at all times. No third party ever holds your keys.
🛡️ Designed for Heirs
Built with long-term recovery in mind — not just for today, but for decades ahead.

How Inheritance Works

The system is designed so heirs can recover funds even many years later, without needing technical expertise. Using Shamir’s Secret Sharing, the seed is split into multiple pieces. These pieces can be distributed to trusted people or stored securely. When the time comes, the required number of shards can be combined to recover the funds.

Current Status

BTCGuardiansHQ is an active project in development. A local version of the explorer is running and early vault functionality (including vault.js with Shamir’s Secret Sharing) has been tested. The project is not yet publicly available. We are focused on building secure, usable tools before wider release.
